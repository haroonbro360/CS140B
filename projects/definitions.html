Internet

The Internet is a worldwide network that connects computers and devices so people can communicate, share information, and access websites and services.

Web

The Web is a system of websites and online pages that we access through the Internet using a web browser.

Internat and Web

The Internet is the worldwide network that connects devices. The Web is the websites and pages we use through the Internet.

ASCII and Unicode

ASCII is a character system that represents letters, numbers, and symbols. Unicode supports many more characters and languages

UTF-8

UTF-8 is a way of encoding text so computers can store and understand different characters and languages.

URL

A URL is the address used to find a webpage on the Internet.

Domin name

A domain name is the easy-to-remember name of a website, like google.com.

HTTPS

HTTPS is the secure version of HTTP. It helps protect information sent between your browser and a website.

HTTP

HTTP is a protocol that allows a web browser and a website to communicate.

IP Adress

An IP address is a number that identifies a device on a network.

DNS

DNS changes website names, like google.com, into IP addresses that computers can understand.

W3C Recommendations

W3C Recommendations are guidelines that help make websites work properly and consistently.

XML, XHTML, HTML, HTML5

XML: A language used to store and organize data. XHTML: A stricter version of HTML that follows XML rules. HTML: The main language used to create webpages. HTML5: A newer version of HTML with more features for modern websites.
