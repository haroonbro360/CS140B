Explain the difference between an absolute link and a relative link. Why would you use relative links?

Absolute links provide the complete URL to a resource, including the protocol (like http:// or https://), domain name, and path to the file. For example, an absolute link might look like https://www.example.com/images/photo.jpg. This type of link is universal and can be accessed from any location on the internet. Relative links, on the other hand, only specify the path to a resource relative to the current page's location. For instance, a relative link could be images/photo.jpg, which assumes the image is in the images folder relative to the current page.

Do links always need to be inside a NAV tag?

Links do not always need to be inside a nav tag. The nav element is specifically intended for major blocks of navigation links, such as primary site navigation. Not all links on a page should be included in a nav element; only those that serve as significant navigation aids should be placed there.
