What is the difference between block tags and inline tags?

Block tags are HTML elements that start on a new line and usually take up the full width available. While Inline tags are HTML elements that do not start on a new line and take up only the space they need

What is the margin, border, and padding?

  • Margin: Margin is the space outside an element's border that separates it from other elements
  • Border: Border is the line that surrounds an element's content and padding.
  • Padding: Padding is the space between an element's content and its border.

What are units of measurement you can use in CSS?

CSS units of measurement are used to set the size of elements, text, margins, padding, and other properties.

When would you use a figure tag?

The figure tag in HTML is used to display images, diagrams, or other content that is related to the main content of a webpage. It is often used with the figcaption tag to add a caption or description.
