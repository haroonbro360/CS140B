According to the instructor, what is the main difference between CSS Grid and CSS Flex?

The usual distinction is that CSS Grid is two-dimensional (it lays out items in rows and columns), while Flexbox is one-dimensional (it arranges items along a row or a column). Your instructor may have used slightly different wording, but this is the standard comparison.

Who decides where a child goes on the page: the child or its parent? Explain using your three-column layout.

The parent decides where the child goes on the page, while the child is placed within the parent according to the layout rules.

  • Parent

    Defines the layout

    Sets the grid or column structure

    Can align, order, or reposition children

  • Child

    Occupies a position within it

    Follows the applicable layout rules

    May influence its own placement through properties such as alignment or grid placement

  • Responsibility

    The parent controls placement

    The layout determines positioning

    The child can influence placement when explicitly allowed
