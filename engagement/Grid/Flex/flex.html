What you learned about Flex and CSS.

I learned that Flexbox in CSS helps arrange items on a webpage. It can place items in a row or column and help organize them neatly. I also learned that CSS is used to style a webpage, including its colors, spacing, and layout. Flexbox makes it easier to create a webpage that looks good on different screen sizes.

Why do you need to have an accessible website? What does that mean?

An accessible website means everyone can use it, including people with disabilities. We need accessible websites so everyone can read information, use links, and understand the content easily. For example, adding descriptions to images helps people who use screen readers. Making a website accessible gives everyone a fair chance to use it.
