CSS

Explain the difference between inline, embedded, and external CSS.

CSS written directly inside an HTML elemnet to change its style. While embedded CSS is written inside the style in the HTML docoument. While external CSS is wriiten in a separate .css file and connected to the HTML page.

Explain why you should only use external CSS.

We should use external CSS because it keeps your HTML clean and lets you use the same CSS file for multiple pages. This makes your website easier to organize, update, and maintain.

What is a selector used for?

A selector is used to choose which HTML element(s) you want to style with CSS.
