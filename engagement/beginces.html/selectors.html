List out the different ways to select an item.

Element/tag selector, ID selector, Class selector

What is the difference between an ID and a Class?

ID: Used for one unique element. Class: Can be used for multiple elements.

What is the difference between a SPAN tag and a DIV tag?

SPAN: Inline element. DIV: Block-level element.

What is the difference between a DIV tag and a HEADER, MAIN, or FOOTER?

DIV: General container with no special meaning. HEADER, MAIN, FOOTER: Semantic tags that describe the purpose of the content.
