5. What is the difference between OL and UL Tags?

Ordered List (OL): This element is used to create a list where the order of items is significant. By default, items in an ordered list are numbered. For example, a recipe or steps in a process would typically use an ordered list. Unordered List (UL): This element is used for lists where the order of items does not matter. Items in an unordered list are marked with bullet points. For instance, a list of ingredients or features can be represented using an unordered list.
