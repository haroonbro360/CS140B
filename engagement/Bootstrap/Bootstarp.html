Can you use Bootstrap on your final project?

Yes, I can use Bootstrap on my final project to make my website look better, more organized, and responsive on different screen sizes.

Which components did you add to your page, and which of them needed Bootstrap's JavaScript to work?

I added components such as a navigation bar, buttons, cards, and a responsive layout. The navigation bar's collapsible menu needs Bootstrap JavaScript to work on smaller screens. The buttons and cards do not necessarily need Bootstrap JavaScript.
