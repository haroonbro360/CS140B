Answers and Questions

The form tag has an "action" attribute. What does it do?

The action attribute tells the browser where to send the information after the user submits the form.

The form tag has a "method" attribute. What does it do?

The method attribute tells the browser how to send the form information to the server.

What is the difference between POST and GET?

  • GET sends form information in the URL. It is usually used to search or request information.
  • POST sends form information in the request body. It is usually used when submitting information.

How do you fill in a form control with a pre-set value, and how is that different from a placeholder?

  • Text box: Use the value attribute to put text inside the box. A placeholder gives a hint.
  • Textarea: Put pre-set text between the textarea tags. A placeholder gives a hint.
  • Select box: Use the selected attribute to select an option by default.
  • Checkbox: Use the checked attribute to select it by default.
  • Radio button: Use the checked attribute to select one option by default.

Main difference: A pre-set value is information already provided in the form. A placeholder is only a hint.

List all the form controls that HTML5 added. Which ones did you use?
