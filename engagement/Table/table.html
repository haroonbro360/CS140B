Answer and Question

Why don't we use the border attribute?

We don't use the border attribute because CSS is a better way to style tables. It keeps the design separate from the HTML and makes it easier to change.

What is the easiest way to color every other row a different color?

The easiest way to color every other row is using the CSS nth-child(even) selector. It gives a different background color to even-numbered rows.

What does the value in the parentheses of your structural pseudo-class mean?

The value inside the parentheses tells the browser which rows to select. For example, even selects rows 2, 4, 6, and 8. Another value is odd, which selects rows 1, 3, 5, and 7.
