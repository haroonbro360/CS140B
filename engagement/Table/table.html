Answer and Question

When do you use a table?

I use a table when I need to organize information into rows and columns, such as a class schedule, student grades, or prices.

When do you not use a table?

I do not use a table to organize the layout of a webpage. I can use CSS Flexbox or Grid for that.

When do you need to do extra work for table accessibility?

I need to do extra work when a table has complicated information, such as multiple headings or merged cells. I should use proper headings and captions so people using screen readers can understand the table.

Which question you asked AI today helped you learn the most, and why?

The question about how to make the Fall 2026 heading stretch across all five columns helped me the most. I learned how to use colspan in HTML.

Did AI ever try to give you more than you asked for, like writing your code? What did you do?

Yes, sometimes AI gives more information than I ask for. I try to ask specific questions and use AI to understand the code instead of just copying it.
