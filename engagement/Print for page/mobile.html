Assignment Questions

Why do we need a viewport meta tag?

We need a viewport meta tag to make the website fit the screen size of different devices, such as phones, tablets, and computers.

When you select the same tag twice, and one says flex-direction: column; and the other says flex-direction: row;, which one takes priority?

Usually, the second rule takes priority if both rules have the same specificity and neither uses !important. The browser uses the last rule.

How do you change the CSS for a web page displayed on a phone?

We can use a media query with @media to change the layout, font size, and other styles for smaller screens.

Pick a website you use on your phone. Name two things it changes on mobile compared to desktop.

I use YouTube on my phone. On mobile, the videos fit the smaller screen, and the navigation buttons are arranged to make them easier to use.

What width did you choose for your breakpoint, and why?

I chose 550 pixels as my breakpoint because it helps the website fit smaller phone screens. At this width, the cards change to one column so they are easier to see.
