Assignment Questions

1. Why is the viewport meta tag important?

The viewport meta tag helps a webpage fit the screen size of different devices, such as phones, tablets, and computers.

2. How can you adjust the CSS for printing?

We can use a print media query in CSS to change the webpage when printing. For example, we can hide the navigation and sidebar.

3. When would you want to adjust the CSS for printing?

We should adjust the CSS for printing when we want a webpage to look clear on paper and save ink.
